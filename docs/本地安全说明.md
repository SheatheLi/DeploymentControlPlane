# 本地安全说明

本包仅为本地可信软件交付模拟器：API 无登录权限、无容器隔离、无多租户模型。只应绑定 127.0.0.1，不得直接部署至公网。子进程执行的是随包提供的固定 `worker_app.py`，请求参数只允许 `isidentifier()` 字符集合的版本号和服务名；没有通用任意代码执行接口。

异常退出可能留下历史子进程。测试和 benchmark 使用 PID 终止已知进程，但生产系统需要 PID identity（如 pidfd）、进程生命周期监督、孤儿清理和原子路由切换。失去 lease 后拒绝 DB promote 不意味着能取消先前已执行的全部外部副作用。不得因此宣称具备生产级安全部署。
